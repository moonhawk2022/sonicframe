三步做出第一支 MV

  1. 加歌曲：支持 MP3 / WAV / M4A / FLAC / OGG。会自动读取歌名、歌手、内嵌封面与内嵌歌词（网易云、QQ音乐下载的文件大多带）；并把音量标准化到 -14 LUFS。
  2. 加歌词：文件自带歌词自动填入；没有就自动联网匹配（按歌名+时长挑最接近的），也可点“联网找歌词”重试、粘贴纯文本或上传 LRC；发现整体偏早/偏晚，用“时间微调”推一下。
  3. 调画面：选比例（抖音/Reels 用 9:16，B 站/YouTube 用 16:9），选配色，点“生成 MV 视频”。

常见问题

导出的视频能直接发抖音吗？
可以。默认导出 MP4（H.264 + AAC），抖音、视频号、小红书、B 站都直接支持。体积默认压到 10MB 以内（按歌曲时长自动算码率，必要时自动降清晰度），长歌选 ≤30MB / ≤60MB 更清晰。
导出卡顿 / 花屏？
实时录制对机器性能敏感。切到 720p、关闭其他占用显卡的标签页，并保持页面在前台。
歌词对不上？
先确认是 LRC（带 [00:12.00] 时间戳）。纯文本只能按字数估算，长句多、节奏快的歌建议做 LRC。
